# Searchify - Lost & Found Portal

A web portal designed to help students reconnect with their lost belongings on campus.

## Features
- **Modern Glassmorphic UI**: Sleek, clean and responsive navigation and hero design.
- **Search & Filter**: Search items by name, category, or location.
- **Report System**: Easy flows to report lost or found items.
- **Statistics Dashboard**: Real-time portal metrics on lost, found, and recovered items.

## Tech Stack
- HTML5
- CSS3 (Vanilla CSS with modern backdrop filters and gradients)

## Getting Started
To view the project locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/geetamgoyal/lost-and-found.git
   ```
2. Open `lost&found.html` directly in any modern web browser or use a live server extension.
